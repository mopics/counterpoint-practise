# Root Hint on Chord Symbols Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** In numeral mode, show the actual root a `**K**` marker set — as `*<Root>` appended to the nearest chord symbol — wherever a marker fires on an event that carries a chord symbol.

**Architecture:** `computeScaleDegrees` already walks every event in document order, consuming markers as it goes; extend that same walk to record, per event, the root of the last marker consumed there (if that event also carries a chord symbol). Thread the result down through `SheetView` into `ChordSymbolRow`, which appends a second, visually subordinate `<tspan>` to the existing chord-symbol text.

**Tech Stack:** React 19, TypeScript, Vitest (unit tests for the data computation; the rendering change is manually verified, consistent with this feature's existing test split).

**Spec:** `docs/superpowers/specs/2026-08-12-root-hint-design.md`

## Global Constraints

- A hint is recorded only for an event where a marker fired **and** that event has a `chordSymbol`. Markers firing with no adjacent chord symbol produce no hint.
- Hint text is the marker's root exactly as written (e.g. `"Eb"`), never reformatted.
- Hint is shown regardless of whether the resulting root actually differs from the previous root — no "did it change" detection.
- Rendering only happens when numeral mode is on; normal notehead view is completely unaffected.
- Hint `<tspan>` styling: `fontSize={10}`, `fontWeight={400}`, `className="fill-green-600"`, appended immediately after the chord symbol's own `<tspan>` (`fontSize={13}`, `fontWeight={700}`, `className="fill-slate-900"`, unchanged from today), as `*` + root text.

Modify the main loop's marker-consuming block (around lines 172-178) to track the last root consumed at this event, and record it as a hint when the event carries a chord symbol:

```ts
  for (const { lineIndex, eventIndex } of allRefs) {
    const event = flattened.lines[lineIndex].events[eventIndex];
    const onsetChar = noteOnsetChar(event, cleanAbc);
    let lastConsumedRoot: string | null = null;
    while (markerIdx < sortedMarkers.length && sortedMarkers[markerIdx].charOffset <= onsetChar) {
      currentRootPc = ROOT_TO_PC[sortedMarkers[markerIdx].root] ?? currentRootPc;
      lastConsumedRoot = sortedMarkers[markerIdx].root;
      markerIdx++;
    }
    if (lastConsumedRoot !== null && event.chordSymbol) {
      linesOut[lineIndex].rootHints[eventIndex] = lastConsumedRoot;
    }

    const key = `${lineIndex}:${event.measureIndex}`;
    if (key !== measureKey) {
      measureKey = key;
      measureAccidentals = {};
    }

    if (event.kind !== 'note' || !event.pitches?.length) continue;
    linesOut[lineIndex].degrees[eventIndex] = event.pitches.map((p) =>
      degreeLabel(currentRootPc, p, flattened.keyAccidentals, measureAccidentals),
    );
    for (const p of event.pitches) {
      if (p.accidental) measureAccidentals[extractLetter(p.name)] = p.accidental;
    }
  }
```

(Only the marker-consuming block and the new `if` after it are new; the measure-tracking and degree-computation code below it is unchanged from what's already in the file.)

In `src/notation/ChordSymbolRow.tsx`, replace the full file with:

```tsx
interface Props {
  events: LayoutEvent[];
  y: number;
  rootHints?: (string | null)[];
}

export function ChordSymbolRow({ events, y, rootHints }: Props) {
  return (
    <g>
      {events
        .filter((e) => e.event.chordSymbol)
        .map((e) => {
          const hint = rootHints?.[e.eventIndex];
          return (
            <text
              key={e.eventIndex}
              x={e.x}
              y={y}
              fontSize={13}
              fontWeight={700}
              fontFamily="ui-sans-serif, system-ui"
              className="fill-slate-900"
            >
              {e.event.chordSymbol}
              {hint && (
                <tspan fontSize={10} fontWeight={400} className="fill-green-600">
                  *{hint}
                </tspan>
              )}
            </text>
          );
        })}
    </g>
  );
}
```

Keep the existing `import type { LayoutEvent } from './layout';` at the top of the file unchanged.
